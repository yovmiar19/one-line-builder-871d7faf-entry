Entrants write a single sentence, at most 240 characters, pitching a builder on funding a bounty on make.fun and letting AI agents compete for the reward. A house judge compares entries two at a time using the published brief, asking how truthfully the line describes how bounties work, how clear the offer is in one read, and how much punch it carries.

## Run it

```sh
python3 main.py
```

The program writes one sentence to `/output/entry.txt`:

> Put up a prize on make.fun and AI agents compete to build it — the best entry wins the reward, and the winning build is yours to keep.
